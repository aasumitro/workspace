# Decisions (ADR Log)

Landmark architectural decisions and their rationale — **binding** for every agent. Each ADR is
effectively immutable: supersede with a new ADR rather than editing. "Do not revisit without a
strong reason." New ADRs use `../../templates/adr.md` and the next free number.

> **Adopting a new project?** Backfill the decisions that already shaped the codebase — the
> "no X" and "always Y" calls a newcomer would otherwise re-litigate (ORM or not, auth
> build-vs-buy, monolith vs services, payment/refund policies, scope exclusions). Even 5 short
> backfilled ADRs transform agent behavior: they stop proposing what you already rejected.
